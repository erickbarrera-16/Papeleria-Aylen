# Papelería Aylen

Sistema web de punto de venta para una papelería. Permite consultar productos, registrar ventas y administrar el inventario.

## Funciones

- Inicio de sesión para administrador y trabajador.
- Consulta y búsqueda de productos.
- Registro de ventas y cálculo del total y cambio.
- Actualización de existencias al confirmar una venta.
- Consulta del historial de ventas.
- Registro, edición y eliminación de productos desde el perfil de administrador.
- Restricciones de acceso según el tipo de usuario.

## Tecnologías

- HTML
- CSS
- JavaScript
- localStorage

## Cómo ejecutar el sistema

1. Descargar o descomprimir el proyecto.
2. Abrir la carpeta que contiene los archivos del sistema.
3. Ejecutar `index.html` en un navegador web.
4. Iniciar sesión con una cuenta de demostración.

## Usuarios de demostración

**Administrador**
- Usuario: `admin`
- Contraseña: `admin123`

**Trabajador**
- Usuario: `trabajador`
- Contraseña: `caja123`

## Almacenamiento

Los productos y las ventas se guardan en el almacenamiento local del navegador. Los datos no se comparten entre computadoras.
